## 行为与发布门槛

- 学习者路径覆盖两周导航、阅读、明显不足答案被拒绝、补充后通过、刷新恢复、取消重置和确认重置。
- 自动化重点覆盖 Day 7 go/no-go 与 Day 14 答辩的结构化输入，并逐日检查主题特有的工程证据字段；资深架构师仍须按上表逐日签署。
- 总进度只统计 `passed`：13 天通过加 1 天待验收显示 93%，14 天全部通过才显示 100%。
- 浏览器回归只验证链接声明为 HTTPS、主机在允许清单内，以及 `target=_blank` 与 `rel=noopener noreferrer`。`npm run audit:links` 才会发起可复现的 HTTP 请求并核对重定向后的主机；网络、DNS、TLS 或超时会明确记为 `UNVERIFIED`，不算通过。网络结果随运行环境和时间变化，不在本文预先声称。
- 自动化不证明学习者本地实验真实，也不替代安全、平台和业务评审签署；界面和计划均明确该边界。
